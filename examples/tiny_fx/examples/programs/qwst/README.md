# Tiny FX Micropython Qw/ST Examples <!-- omit in toc -->

These are micropython examples for driving Tiny FX from a sensor plugged into its Qw/ST connector.

- [Examples](#examples)
  - [Light Level](#light-level)
  - [Temperature Reading](#temperature-reading)
  - [Spirit Level](#spirit-level)


## Examples

### Light Level
[light_level.py](light_level.py)

Light Tiny FX's mono outputs with a flicker when the room gets dark, using a light sensor on Qw/ST.

### Temperature Reading
[temperature_reading.py](temperature_reading.py)

Show the temperature on Tiny FX's RGB output, using an environment sensor on Qw/ST.

### Spirit Level
[spirit_level.py](spirit_level.py)

Use Tiny FX's mono outputs as a spirit level, driven by an accelerometer on Qw/ST.
