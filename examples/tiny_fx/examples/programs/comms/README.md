# Tiny FX Micropython Comms Examples <!-- omit in toc -->

These are micropython examples for controlling other Tiny FX boards from this one over I2C.

- [Examples](#examples)
  - [Dual FX](#dual-fx)
  - [Multi FX](#multi-fx)


## Examples

### Dual FX
[dual_fx.py](dual_fx.py)

Play wave and rainbow animations across the outputs of this Tiny FX and another Tiny FX connected by I2C and running as an I2CTarget.

### Multi FX
[multi_fx.py](multi_fx.py)

Play wave and rainbow animations across the outputs of this Tiny FX and multiple other Tiny FX boards connected by I2C and running as an I2CTarget.
