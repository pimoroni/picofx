# Mighty FX Micropython Qw/ST Examples <!-- omit in toc -->

These are micropython examples for driving Mighty FX from a sensor plugged into its Qw/ST connector.

- [Examples](#examples)
  - [Light Level](#light-level)
  - [Weather Reading](#weather-reading)
  - [Spirit Level](#spirit-level)


## Examples

### Light Level
[light_level.py](light_level.py)

Bring MightyFX's lights up when the room gets dark, read from a light sensor on Qw/ST.

### Weather Reading
[weather_reading.py](weather_reading.py)

Show the temperature on MightyFX's RGB outputs as a bargraph, read from a weather sensor on Qw/ST.

### Spirit Level
[spirit_level.py](spirit_level.py)

Use MightyFX's RGB outputs as a spirit level, read from an accelerometer on Qw/ST.
