# Shared Examples <!-- omit in toc -->

These are examples that more than one board's picker offers through Discover. They are not copied onto any board's FX drive.

- `examples/sounds/` holds example sounds for the picker's Sound tab, each in the folder of its section in `sections.txt`. Each is a seamless loop.

The sounds come from [fx-sounds](https://github.com/pimoroni/fx-sounds) at commit `536d9056`, whose [gallery](https://pimoroni.github.io/fx-sounds/) also has each with reverb, and some room tones. These are its dry versions, resampled from 44.1kHz to 22.05kHz as 16-bit mono WAV files. They are dedicated to the public domain under CC0, as `LICENSE-SOUNDS` says.
